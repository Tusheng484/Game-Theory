# 博弈论学习笔记

一套基于 Obsidian 的中文博弈论笔记。可以按 L01–L11 从头学习，也可以从知识点索引查阅定义、推导和例题。知识点之间用双向链接连接，便于回查前置概念和相关课次。

## 从哪里开始

| 入口 | 内容 |
| --- | --- |
| [学习首页](博弈论/00-导航/学习首页.md) | 从第一讲开始、继续学习或查找知识点 |
| [课程路线](博弈论/00-导航/课程路线.md) | 按课件顺序浏览各讲和学习进度 |
| [课程地图](博弈论/00-导航/课程地图.canvas) | 在 Obsidian Canvas 中查看全课程，点开卡片进入课次页 |
| [知识点索引](博弈论/00-导航/知识点索引.md) | 按概念查找笔记及相关课次 |

课程从基本概念、纳什均衡和混合策略讲起，接着讨论扩展式博弈、多重均衡和子博弈完美均衡，最后进入不完全信息博弈、拍卖、VCG 机制设计、最优机制和完美贝叶斯均衡。知识点笔记从直觉过渡到正式定义和求解步骤，结合例题解释适用条件与常见误区。

## 在 Obsidian 中打开

1. 克隆仓库。

   ```bash
   git clone https://github.com/Tusheng484/Game-Theory.git
   ```

2. 在 Obsidian 中选择「打开本地仓库」，打开 `Game-Theory/博弈论` 文件夹，然后进入「学习首页」。
3. 启用社区插件 **Dataview** 以显示课程进度和知识点索引。启用 **Breadcrumbs** 后，可以按前置和后续关系浏览概念。首页启动、快捷建笔记、PDF 选区引用和可编辑图解的配置见 [建设与维护规划](博弈论/00-导航/建设与维护规划.md)。

也可以在 GitHub 直接浏览 [课次笔记](博弈论/01-课次) 和 [知识点笔记](博弈论/02-知识点)。

## 仓库结构

| Vault 目录 | 内容 |
| --- | --- |
| `00-导航` | 学习首页、课程路线、课程地图、知识点索引和维护规划 |
| `01-课次` | 各讲的学习目标、知识点顺序、小结与课件入口 |
| `02-知识点` | 概念定义、求解方法、例题、概念联系和来源 |

| `04-资料` | 课程课件、补充资料和附件 |
| `05-图解` | 可编辑的博弈树等图解 |
| `90-模板` | 课次、知识点和资料记录模板 |

新增资料可从 [新资料收件箱](博弈论/03-收件箱/新资料收件箱.md) 开始。先记录来源，再决定补进哪一讲或哪个概念，最后核对链接和引用页码。
