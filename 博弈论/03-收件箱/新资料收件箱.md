# 新资料收件箱

[[学习首页|← 学习首页]] · [[建设与维护规划]]

1. **收进来。** 把新增课件、文章或图片放入 `04-资料/补充资料`。网页资料在笔记里记录网址、题名及相关章节。
2. **确定归属。** 在 `03-收件箱` 用「资料记录模板」建一页。写清材料回答的问题，检查已有知识点能否接入。涉及新概念时，用 QuickAdd 新建知识点。
3. **接进课程。** 在目标笔记补讲解、例题或出处，更新相关课次链接。新增课次可用「课次模板」，填写数字课次，再补相邻导航和 Canvas 卡片。
4. **完成记录。** 点开引用和双链核对，把资料记录的 `status` 改为 `已接入`，写明更新到了哪一页。

## 待整理资料

```dataview
TABLE WITHOUT ID file.link AS "资料记录", file.ctime AS "记录创建时间"
FROM "03-收件箱"
WHERE type = "resource" AND status = "待处理"
SORT file.ctime ASC
```
