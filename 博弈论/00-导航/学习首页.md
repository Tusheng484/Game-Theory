## 继续学习

```dataview
TABLE WITHOUT ID file.link AS "下一讲", study AS "学习进度"
FROM "01-课次"
WHERE type = "lesson" AND study != "已学完"
SORT (study = "学习中") DESC, lesson ASC
LIMIT 1
```

在课次页属性里更新 `study`。这里会优先列出学习中的课次，其次列出最早的未学课次。
