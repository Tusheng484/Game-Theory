# 知识点索引

[[学习首页|← 学习首页]] · [[课程路线]] · [[课程地图.canvas|课程地图]]

每个概念一页。按 `Ctrl+O` 输入中文名或英文别名可以快速打开笔记。打开概念后，通过局部图谱查看相关笔记，或用 Breadcrumbs 的矩阵按关系回查。

```dataview
TABLE WITHOUT ID file.link AS "概念", lessons AS "相关课次", status AS "整理进度"
FROM "02-知识点"
WHERE type = "concept"
SORT file.name ASC
```

在命令面板运行「QuickAdd：新建知识点」，或在 `02-知识点` 建笔记后插入「知识点模板」。新增笔记会自动出现在这里。
