# 建设与维护规划

[[学习首页|← 学习首页]] · [[课程路线]] · [[知识点索引]] · [[新资料收件箱]]

## 第一阶段 · 搭建学习框架

本仓库以现有 L1–L11 课件为主线。逐讲学习从「课程路线」进入。复习从「知识点索引」、局部关系图或 Breadcrumbs 进入。Canvas 概览用于看清各讲在课程中的位置。

| 位置 | 放什么 | 如何更新 |
| --- | --- | --- |
| `00-导航` | 首页、课程路线、课程地图、知识点索引和本规划 | 课程路线与索引读取笔记属性。新增课次时补一张 Canvas 卡片 |
| `01-课次` | 每讲一页，汇总目标、学习顺序、来源和知识点链接 | 用「课次模板」新增。`lesson` 用递增整数 |
| `02-知识点` | 每个核心概念一页，跨课次复用 | 用 QuickAdd 的「新建知识点」或插入「知识点模板」 |
| `03-收件箱` | 收件箱及待整理的来源记录 | 先记来源和疑问，整理后改 `status` 并补目标链接 |
| `04-资料` | 课件副本、补充资料和图片附件 | 保留稳定文件名，正文按页码定位 |
| `05-图解` | 可编辑的 Excalidraw 图解 | 用「概念名-博弈树」等可辨认的名称，嵌入使用它的笔记 |
| `90-模板` | 课次、知识点、资料记录模板 | 修改结构时同步更新本页字段约定 |

## 第二阶段 · 逐讲撰写与核对

1. **先做 L1、L2 样板。** 阅读课件，标定实际页码，挑出需要独立复习的概念。完成知识点讲解、例题与链接后，在 Obsidian 查看公式、表格和导航效果。
2. **按课件顺序覆盖 L3–L6。** 补齐混合策略与动态博弈。先建立每讲的概念顺序，再补模型、求解步骤和例题。需要解释决策节点、信息集和行动时，用 Excalidraw 绘制并嵌入博弈树。
3. **覆盖 L7–L11。** 对课件中涉及的类型、信念、激励与机制逐一定义。推导时明确符号、假设和适用条件，把共用概念链接回已有笔记。
4. **做跨讲复习。** 检查概念的前置链接，找出适合比较的概念并写清联系。将关键路径补到课程地图，每条线用明确的关系名。

### 每讲的交付标准

- 写清本讲要回答的问题、建议学习顺序，以及与前后课程的关系。
- 概念正文保留在知识点页。课次页负责串联概念、讲解应用顺序和回指课件。
- 每条课件出处在 Obsidian 中点击确认，`#page=N` 用 PDF 阅读器从 1 开始计数的实际页码。
- 完成上述检查后，把课程页的 `status` 改为 `已整理`。`study` 由学习者按实际学习进度更新。

### 每个知识点的写作标准

1. **先讲直觉。** 用通俗语言回答这个概念在解决什么问题、什么时候会遇到它。
2. **给出定义和适用条件。** 逐一解释符号和假设。存在不同约定时，写明课件所采用的约定。
3. **展开推理。** 对照定义解释求解或判断步骤，交代每一步的理由。需要证明时，写清结论和关键中间环节。
4. **给一道完整例题。** 题目给足条件，解法逐步推导并解释结论。按内容选择收益矩阵、公式或博弈树。
5. **说明边界和联系。** 给出容易混淆的概念、求解中高频的错误、结论的适用范围。选择直接前置概念写入 `up`，正文用一句话说明链接两端的关系。
6. **核对出处和呈现。** 按实际 PDF 页码落链。检查行内公式、独立公式、矩阵和图中文字在阅读视图中清楚可读。

## 字段与链接约定

| 属性 | 类型 | 约定 |
| --- | --- | --- |
| `type` | 文本 | `lesson`、`concept` 或 `resource` |
| `lesson` | 数字 | 课次顺序，例如 `2`，显示编号为 `L02` |
| `status` | 文本 | 课次和知识点用 `待整理`、`整理中`、`已整理`。资料记录用 `待处理`、`已接入` |
| `study` | 文本 | 仅在课次页使用，取 `未开始`、`学习中` 或 `已学完` |
| `aliases` | 列表 | 常见中文异名与英文术语，便于快速切换器检索 |
| `lessons` | 链接列表 | 知识点涉及的课次，可以有多讲 |
| `up` | 链接列表 | 知识点的直接前置概念。Breadcrumbs 通过逆向 `down` 列出后续概念 |
| `cssclasses` | 列表 | 保留模板的类名，以应用对应的阅读样式 |

属性中的内部链接使用带引号的列表项，例如 `- "[[已有笔记名]]"`。在正文写出「为什么相关」，用普通双链指向已有页面。确认直接依赖后再添加 `up`，能避免概念层级里的环。

## 插件怎么配合

- **Homepage** 打开 [[学习首页]]，保留上次的标签页。命令面板中的 `Homepage: Open homepage` 可随时返回。
- **Dataview** 根据属性生成课程路线、下一讲、知识点索引和待整理资料。改笔记属性后，页面自动更新。
- **QuickAdd** 用 `Ctrl+Alt+N` 从模板创建知识点文件。核心 Templates 和 Templater 共用这个模板目录。
- **Breadcrumbs** 用 `up`、`down` 的矩阵检查当前概念的前置和后续。正文继续记录具体关系，例如「用来判断」或「是其精炼」。
- **PDF++** 选中课件片段，复制选区链接到「课件出处」。定位整页时用普通 `#page=` 链接。
- **Excalidraw** 在 `05-图解` 创建和维护源图。图中标明轮到谁行动、各分支行动、信息集和终点收益，复杂图在正文旁补文字说明。
- **Git** 在一讲或一组相关概念核对完后保存一次提交。操作和恢复流程见下节。

## Git 与恢复

Git 根目录是 Obsidian 仓库的上一级，分支为 `main`。原始课件留在外层，仓库内的副本是笔记链接的目标。Git 记录仓库内的课件副本、笔记、图解和通用 Obsidian 配置。工作区状态、社区插件二进制和本机插件数据由 `.gitignore` 排除。

- 在 Obsidian 命令面板执行 Git 的「提交并指定消息」命令，或在项目根目录执行 `git status`、`git diff`，核对改动后保存提交。可用消息 `补齐 L02 的最佳反应与纳什均衡`。
- 查看单个文件的版本用 `git log -- <路径>`。想从某一版本取回内容时，先用 `git show <提交>:<路径>` 查看，另存并与当前内容比较后再恢复。课件原件在项目根目录，可核对后重新复制到 `04-资料/课程课件`。
- 新设备打开内层 `博弈论` Vault 并安装所需社区插件。Homepage 选 `00-导航/学习首页.md`、保留标签并用阅读视图。QuickAdd 添加 `Template` 类型的「新建知识点」，模板 `90-模板/知识点模板.md`，保存目录 `02-知识点`，文件名用 `{{VALUE}}`。点击该命令旁的闪电按钮，在快捷键设置为它绑定 `Ctrl+Alt+N`。Excalidraw 图解目录选 `05-图解`。Git 插件的自定义路径留空，由它自动识别上一级项目根目录。Breadcrumbs 使用默认 `up` / `down`。通过「外观 → CSS 代码片段」可以切换 `game-theory`。
- 需要连接远程时，在明确托管地址后配置 `origin`，核对将同步的笔记和课件，再执行首次推送。日常本地提交可独立使用。

配置可以逐项恢复。Homepage 的启动页和阅读视图在插件设置中切换。QuickAdd 的「新建知识点」可移除，快捷键可单独清空。Templates、Templater、附件和 Excalidraw 的目录可在各自设置中更改，已创建文件留在原位置，迁移时通过 Obsidian 移动以更新链接。

## 下一次更新的检查清单

- [ ] 从首页可以进入相关课次或知识点。
- [ ] 新笔记的类型、课次、状态以及前置关系都能被索引识别。
- [ ] 课件链接、引用页码、图解嵌入和双链可以打开。
- [ ] 知识点有直觉、定义和条件、推理、一道带解法的例题、关联及出处。
- [ ] 阅读视图中的公式、图表和长内容可读，Git 变更范围经过检查。
